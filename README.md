### 01 · Enterprise AI Operations Platform

**Agentic Investigation · LangGraph · MCP · Workflow Reliability**

An enterprise investigation platform that coordinates evidence collection across Jira and GitHub to investigate delivery risks and produce evidence-based findings.

- **Multi-agent workflow orchestration:** Coordinates planning, investigation, evidence aggregation, analysis, evaluation, and reporting through LangGraph.
- **Enterprise tool integration:** Connects Jira and GitHub through MCP-integrated tools with validated arguments.
- **Evidence-aware evaluation:** Assesses investigation results before deciding whether to report, retry, request human review, or terminate.
- **Bounded retries and replanning:** Uses previous failures and missing evidence to guide subsequent investigation attempts.
- **Human-in-the-loop control:** Supports workflow interruption, human decisions, and resumption.
- **Persistent business memory:** Stores eligible investigation findings using SQLite and SQLAlchemy.
- **Application delivery:** FastAPI backend, Streamlit interface, Docker Compose, and AWS EC2 deployment experience.

### 02 · Enterprise AI Document Intelligence System

**Advanced RAG · Hybrid Retrieval · Reranking · Evaluation**

A document intelligence system focused on improving retrieval relevance and answer quality through hybrid search, query refinement, reranking, and systematic evaluation.

- **Hybrid retrieval:** Combines BM25 keyword search with semantic vector retrieval to capture exact-term matches and semantically related content.
- **BGE embeddings:** Uses `BAAI/bge-base-en-v1.5` for semantic document representation.
- **Query rewriting:** Refines user queries to improve retrieval for ambiguous or underspecified questions.
- **Cross-encoder reranking:** Re-scores retrieved candidates to prioritize relevant context before generation.
- **Retrieval evaluation:** Evaluates the quality of retrieved context.
- **Generation evaluation:** Assesses the quality and grounding of generated answers.
- **LLM-as-a-Judge:** Uses model-based judgments to evaluate responses against defined criteria.

**Technology:** Python · RAG · BM25 · BGE Embeddings · FAISS · Cross-Encoder Reranking · Query Rewriting · LLM-as-a-Judge · Retrieval Evaluation · Generation Evaluation
